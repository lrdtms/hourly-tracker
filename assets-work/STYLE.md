# Style (locked)

Flat vector shapes, rounded caps and corners, no outlines, no gradients, no shadows, no texture.
One mark per icon, centred, large and simple enough to survive at 48dp.

| Token | Value | Use |
|---|---|---|
| teal | `#1B6E66` | brand ground / main mark colour |
| mint | `#5CC4B4` | teal's light partner on dark grounds |
| ink | `#1F201D` | dark ground |
| paper | `#F6F5F1` | light ground / mark on dark |
| orange | `#EB6834` | the single warm accent, used once per mark |

Motion (splash): 1.8 s, 20 fps, ease in-out, loops cleanly, first frame == last frame == the static mark.
Type: none inside images. App name set in Instrument Serif in the app itself.
